# ❤️ Heart Disease Prediction

### 👩‍💻 Nanthini

> 🤖 Machine Learning project for predicting and classifying heart disease risk using Python and Scikit-learn.

---

## ✨ About

This project applies *Machine Learning algorithms* to analyze patient health data and predict the likelihood of heart disease. It also classifies patients into *High Risk* and *Low Risk* categories.

## 🧠 Algorithms
Algorithm | Purpose
📈 Logistic Regression | Predict heart disease risk
🌳 Decision Tree Classifier | Predict heart disease risk
🎯 Random Forest Classifier | Classify risk as High / Low
## 📊 Features Used

- 👤 *Age* — Patient age
- ♂️ *Sex* — Male / Female
- 💔 *ChestPain* — Type of chest pain
- 🩸 *BP* — Resting blood pressure
- 🧪 *Cholesterol* — Serum cholesterol level
- 📈 *MaxHR* — Maximum heart rate achieved
- ⚡ *ExerciseAngina* — Exercise induced angina

The classification model uses One-Hot Encoding for categorical features and Standard Scaling for numerical features.
